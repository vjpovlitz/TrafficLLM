# TrafficLLM

A deep learning project for traffic analysis using computer vision and LLMs.

## Structure
- data_processing/: Data preparation and processing scripts
- refinement/: Interactive refinement and feedback system
- training/: Model training scripts

## Setup
1. Install requirements: pip install -r requirements.txt
2. Configure paths in path_config.py
3. Run training with python training/train.py

## Usage
Run python data_visualization/visualize_data.py to start the interactive visualization and refinement process.
